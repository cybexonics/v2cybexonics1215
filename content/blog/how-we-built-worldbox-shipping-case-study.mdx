# Case Study: Custom Shipping Calculator & Admin Panel for Worldbox Shipping Pvt. Ltd.

Most web agencies build websites. We build tools that make businesses run better.

When Worldbox Shipping Pvt. Ltd. — a Pune-based global freight forwarding company operating across Mumbai, Pune, and Hyderabad — came to us, they did not just need a website. They needed a complete custom platform that their team could manage independently and their clients could use to get instant freight quotes.

We built it in 2 weeks.

## The Challenge

Worldbox handles complex freight pricing — rates change based on:

- **Shipment type** — Import or Export
- **Container size** — 20ft or 40ft
- **Mode** — Sea freight or Air freight
- **Route** — Origin and destination
- **Cargo type** — Commercial, personal, or project cargo

Previously, every client enquiry required a manual back-and-forth over email or phone to get a quote. This was slow for clients and time-consuming for the Worldbox team.

They needed a smarter solution.

## What We Built

### 1. Custom Freight Rate Calculator

We built a fully custom shipping calculator on the Services page that allows clients to:

- Select **Import or Export**
- Choose **Sea Freight or Air Freight**
- Select container size — **20ft or 40ft** for sea, weight-based for air
- Get an **instant rate estimate** based on current pricing

This eliminated hours of back-and-forth for the Worldbox team and gave clients immediate answers — a massive improvement in user experience.

### 2. Admin Panel — Full Control Without a Developer

We built a custom admin panel that gives the Worldbox team complete control over their platform:

- **Update freight rates** — change import/export pricing for 20ft, 40ft, air and sea instantly
- **Manage blog posts** — publish shipping news, regulatory updates, and industry articles
- **Edit service pages** — update descriptions, add new services, change contact details
- **No developer needed** — the entire platform is manageable by non-technical staff

This means Worldbox never has to call us to change a price or update content — they own their platform completely.

### 3. Full Website with White Space Design

The website itself was built using **white space design principles** — clean, minimal layouts that let the content breathe and guide the visitor's eye naturally toward key actions.

Key pages built:
- Home — hero, services overview, trust signals, CTA
- Services — freight calculator embedded, service breakdown
- About — company story, team, MTO license credentials
- Blog — managed through admin panel
- Contact — multi-field enquiry form with direct email routing

## Technology Stack

| Layer | Technology |
|---|---|
| Frontend | Next.js 14, React, Tailwind CSS |
| Calculator logic | Custom React state management |
| Admin panel | Next.js API routes + secure auth |
| Database | Lightweight JSON / file-based for rate storage |
| Deployment | Vercel — zero downtime, global CDN |
| Design principle | White space — minimal, professional, fast |

## The Results

- **Delivered in 14 days** — full platform, not just a website
- **Instant quotes** — clients get freight estimates without calling
